# AGENTS.md

Instructions for agents working in trovium.

## What this is

Python ≥3.13, uv-managed collection of **single-purpose CLI tools** replacing
the *arr media-automation stack. Steps exchange plain files/JSON over
stdin/stdout; no shared database, no hidden state (constitution principles
XXV–XXVII in `.specify/memory/constitution.md` — read it before feature work).

Feature work runs through the spec-kit flow: `/speckit.specify → /speckit.plan
→ /speckit.tasks → /speckit.implement` (commands live in
`.opencode/commands/speckit.*.md`; specs in `specs/NNN-slug/`, one branch per
feature). Implementation does not start without an agreed spec (XXIV).

## Commands

```sh
uv sync                 # first: prepare the environment (uv only; no pip/system installs)
scripts/check.sh        # THE canonical check: ruff lint+format, mypy strict, pytest, prettier, markdownlint, shellcheck
uv run pytest tests/integration/test_client_ingest.py   # one test file
uv run pytest -k "single_file"          # one test by name
uv run ruff check --fix . && uv run ruff format .       # lint autofix + format
uv run mypy .           # `mypy .` is accepted and covers src/ + tests/ + tools/
```

`scripts/check.sh` runs locally, at every git boundary, and in CI — the same
command. Never declare work finished with it red (XXII).

## Rules that gate you (they will refuse, not warn)

- **No direct commits to `main`** — the pre-commit hook blocks the branch
  (II). Feature branches `NNN-slug`, squash-merge through PRs.
- **Conventional Commits**, subject ≤72 chars, no emoji, no AI-branding
  references (III). Pre-commit also scans staged files for secrets and
  forbidden paths.
- **Protected files**: editing `.specify/gates/policy.json` is agent-denied;
  `.specify/memory/constitution.md` is ask-gated. Commits touching either need
  a `Protected-Change: <path>` trailer (VIII/IX).
- **One runtime dependency**: `httpx` only. `tests/unit/test_dependency_budget.py`
  fails CI on any addition — changing the budget means amending spec/plan
  first, not the pyproject alone.
- **Do not weaken gates**: setting `GATES_SKIP=…` on a command raises an
  approval prompt; `--no-verify` is flagged by the hook chain itself.
- **Spec gate parsing**: an in-development spec's numbered criteria are parsed
  and executed as acceptance checks; a merged/Draft spec is informational, but
  a mismatched tasks/spec state can still fail CI parity.

## Projection / vendored surfaces (do not hand-edit)

- `.specify/**` and `.opencode/commands/speckit.*.md` are projected/generated by
  spec-kit (XX). They are excluded from formatters and linters on purpose;
  regenerate them through the tool, never by patching files.
- `.opencode/plugins/gates/`, `.opencode/skills/`, and `tools/` are
  hand-written and in scope for linting.

## Machine quirks

- `/opt/homebrew/bin/task` is **Taskwarrior**, not go-task: gates' `task`
  orchestrator cannot be used here. `scripts/check.sh` (custom orchestrator)
  exists precisely for that. If you must run a Taskfile, use
  `uvx --from go-task-bin task …`.
- PR **descriptions and titles must not contain emoji** — the message rules
  reject them and the `gates` check fails (seen on real PRs).
- A `git push` can complete without GitHub creating the workflow run (webhook
  lag). After pushing, confirm a run exists for the pushed SHA
  (`gh api repos/sdpilon/trovium/actions/runs?head_sha=$SHA`) before waiting
  for CI.

## Testing notes

- Layers: `tests/unit/`, `tests/contract/` (CLI + record contracts pinned in
  `specs/…/contracts/`), `tests/integration/`.
- Real qBittorrent behavior is exercised via `tools/qbt-live-rig/` (Linux-only,
  two local instances + tracker, no root); stub transports live behind
  `httpx.MockTransport`. Never claim live verification
  that only stubs prove.
- Client gotchas (5.x `stop` vs `pause`, `root_path` vs `content_path`, async
  `setLocation` + recheck) are catalogued in `tools/qbt-live-rig/README.md`.
